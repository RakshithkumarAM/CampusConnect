# CampusConnect

### Improving communication between students and lecturers

CampusConnect is an early-stage project inspired by a real campus problem: students may spend unnecessary time waiting to meet lecturers because they cannot easily confirm availability.

## Goal

Build a simple system that helps students check lecturer availability and request meetings, with a long-term goal of automating availability updates using timetable information.

## Planned features

- Student and lecturer accounts
- Lecturer approval
- Lecturer availability information
- Student meeting requests
- Timetable-based availability automation

## Current status

Early prototype. Features and reliability are still being tested.

## Technology

- Python
- Streamlit
- SQLite

## Development approach

AI tools assisted with parts of the code. The project is being developed and tested while learning the underlying programming concepts.

## Future work

- Improve mobile usability
- Validate the problem with students and lecturers
- Investigate automatic timetable-based availability
- Test privacy, security, and reliability before any real campus deployment
